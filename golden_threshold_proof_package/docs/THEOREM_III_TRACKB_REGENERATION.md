# Track-B Theorem III regeneration route

The theorem-facing Theorem III object is generated by:

```bash
python scripts/regenerate_theorem_iii_trackb_from_scratch.py \
  --from-scratch \
  --force \
  --workers 64 \
  --copy-to-stage-cache
```

The canonical settings hard-coded in the harness are:

```text
K = 0.9716350
M = 8192
nu = 1.001
radius = 3e-5
cutoff = full
tail_start = 0.90
minimum relative margin = 0.25
maximum Z bound = 0.5
```

The script reconstructs the selected H1-polished seed from the Phase 4I candidate summary by preferring:

```text
K = 0.9716350,
M_out = 8192,
cutoff = full,
converged_H1 = true,
then smallest derivative/scalar residuals.
```

It then installs the final Phase-6 artifact into:

```text
artifacts/final_discharge/stage_cache/theorem_iii.json
```

This installation step is what makes the downstream theorem-builder use the Track-B lower-anchor certificate rather than the older historical Theorem III prototype path.
