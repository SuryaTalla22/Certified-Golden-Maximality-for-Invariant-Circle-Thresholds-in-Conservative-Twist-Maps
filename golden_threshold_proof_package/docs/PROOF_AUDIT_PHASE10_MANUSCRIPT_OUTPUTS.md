# Phase 10: Manuscript Tables and Figures

Phase 10 adds a reviewer-facing manuscript-output layer.  The purpose is to make the tables and figures that appear in the paper reproducible from the proof-audit payloads, rather than hand-typed into the manuscript.

## Entry points

```bash
python -S scripts/generate_manuscript_audit_tables.py --strict
python -S scripts/generate_manuscript_audit_figures.py --strict
python -S scripts/generate_manuscript_audit_outputs.py --strict
```

The scripts are standard-library only and read the Phase 2--7 proof-audit JSON payloads.

## Generated manuscript tables

- `tables/proof_audit/lower_corridor_segments.tex`
- `tables/proof_audit/upper_obstruction_margin.tex`
- `tables/proof_audit/transport_budget.tex`
- `tables/proof_audit/domain_grammar_counts.tex`
- `tables/proof_audit/replay_protocol.tex`

Each table begins with an auto-generation comment and is derived from proof-audit JSON/CSV payloads.

## Generated manuscript figures

- `figures/proof_audit/lower_chain_margins.pdf`
- `figures/proof_audit/upper_obstruction_margin_decomposition.pdf`
- `figures/proof_audit/transport_budget_waterfall.pdf`
- `figures/proof_audit/arithmetic_domain_route_counts.pdf`
- `figures/proof_audit/replay_protocol_tiers.pdf`

The figures are lightweight vector PDFs generated by `kam_theorem_suite.audit.manuscript_audit_outputs` without third-party plotting dependencies.

## Manifest

The script writes:

- `artifacts/proof_audit/manuscript_outputs/manuscript_audit_outputs_manifest.json`

The manifest records source-payload SHA-256 hashes, output SHA-256 hashes, the known lower-gap status, and the rule that manual editing is not allowed.
